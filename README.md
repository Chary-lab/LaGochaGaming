# LaGochaGaming

## Descripción del proyecto

LaGochaGaming es el sitio web de la comunidad de gaming de LaGocha. El proyecto está construido con tecnologías web vanilla (HTML, CSS y JavaScript) y cuenta con varias secciones para ofrecer contenido a la comunidad, incluyendo galería, sorteos, cine y un espacio comunitario.

## Stack tecnológico

- **HTML5** - Estructura y marcado semántico
- **CSS3** - Estilos y diseño responsive (`style.css`)
- **JavaScript Vanilla** - Lógica e interactividad (`main.js`)
- **Sin frameworks** - Proyecto ligero sin dependencias externas pesadas

## Estructura de archivos

```plaintext
D:\Gocha\
├── index.html      # Página principal
├── comunidad.html  # Página de comunidad
├── galeria.html    # Galería de contenido
├── sorteo.html     # Sección de sorteos
├── cine.html       # Sección de cine
├── main.js         # Lógica y funcionalidades JavaScript
├── style.css       # Estilos globales
└── README.md       # Documentación del proyecto
```

## Instrucciones de setup

### Requisitos
- Navegador web moderno (Chrome, Firefox, Edge, Safari)
- Servidor local para desarrollo (opcional, pero recomendado)

### Pasos para ejecutar

1. **Clonar o descargar** el repositorio en tu máquina local.
2. **Iniciar un servidor local** en el directorio raíz del proyecto. Algunas opciones:

   #### Con Visual Studio Code
   - Instalar la extensión [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
   - Abrir el proyecto en VS Code
   - Click derecho en `index.html` → `Open with Live Server`

   #### Con Python
   ```bash
   # Python 3
   python -m http.server 8000
   ```
   Luego navegar a `http://localhost:8000`

   #### Con Node.js
   ```bash
   npx serve .
   ```
   Luego navegar a la URL que te indique el comando.

3. **Abrir en el navegador** y navegar por las diferentes páginas del sitio.
